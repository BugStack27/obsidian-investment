# 发版术语对照表

写 release 汇总信息时，命中本表直接使用「面向用户表述」列，避免把技术标识写进面向非技术用户的发布说明。未命中且含义不确定的术语必须先向用户确认，确认后补进本表供以后复用。

| 原词/缩写 | 含义 | 面向用户表述 |
| --- | --- | --- |
| 记录块 | 笔记中的 `fund-record` / `stock-record` 代码块 | 笔记里的交易表格 |
| 写回 | 把弹窗录入的交易保存到笔记里的代码块 | 保存到笔记 |
| 加减仓 | 加仓 / 减仓 / 分红三类交易的录入入口 | 记一笔买卖 |
| 净值走势 | 基金单位净值随时间变化的曲线 | 基金净值曲线 |
| 现金分红 | 基金或股票派发的现金红利 | 分红 |
| 手续费 | 买卖时产生的交易费用 | 手续费 |
| 导出 CSV | 把交易记录下载为表格文件 | 导出表格文件 |
| 图表自适应 | 图表随容器尺寸变化重新排版 | 图表跟随窗口大小变化 |
| 插件 ID | `manifest.json` 的 `id`，决定插件在库中的目录名 | 插件目录名 |
| minAppVersion | 插件要求的最低 Obsidian 版本 | 需要的最低 Obsidian 版本 |
