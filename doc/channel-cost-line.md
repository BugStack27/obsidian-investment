# 趋势通道持仓成本线 — 决策记录

> 状态：✅ 已验收（2026-09-21）

## 1. 目标与范围

在指标分析弹窗与信号弹窗的趋势通道图上叠加一条持仓成本水平参考线，用于对比当前净值/均线相对成本的位置（浮盈或浮亏）。只做展示：不加图例开关，不做逐日成本趋势，原有净值线、均线、标准差通道与买卖标记均不改动。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 成本口径 | 加权平均成本 `fund.summary.avgCostPerShare`（元/份，净值口径） | 与界面「持仓成本」一致，随买卖变动 |
| 显隐 | 常显，不提供开关或图例项 | 实现最简；`markLine` 语义天然不进图例 |
| 样式 | 琥珀金 `#D97706` 虚线，标签「持仓成本」+ 四位小数（等宽） | 与买红/卖绿/均线蓝区分 |
| 生效入口 | 指标分析弹窗与信号弹窗同时生效 | 两者共用 `buildChannelOption`，一处改动两端生效 |
| 无效值 | 成本缺失或 `<= 0` 不渲染该线 | 无持仓时画线会误导 |

## 3. 交付物

| 文件（相对路径） | 职责 |
|------|------|
| `src/ui/charts/trendChannel.ts` | `buildChannelOption` 新增 `holdingCost` 参数，有效时向 nav 系列追加水平 `markLine` |
| `src/ui/channelModal.ts` | `renderChannel` 传入 `summary.avgCostPerShare`（`> 0` 才传） |
| `src/ui/signalModal.ts` | `renderChannel` 传入 `d.summary?.avgCostPerShare`（`summary` 可能为 `null`，需兜底） |

## 4. 关键修正与教训

- **成本线需要「可见但不可交互」** → 用 `markLine` 承载，天然不进图例、不改 tooltip，无需额外开关逻辑。
- **无持仓基金的成本为 0** → 传入前判 `> 0`，否则会画出一条贴底的假成本线。
- **两个入口各传各的成本** → 数据接入必须覆盖 `channelModal` 与 `signalModal`，切换基金时随该基金成本刷新。

## 5. 已知边界

- 线为当前成本快照，不反映历史成本变化。
- 不可隐藏，不参与 tooltip。
- 无持仓或成本 `<= 0` 的基金图上没有这条线。

## 6. 后续候选

- 若需要显隐控制，可在通道配置中增加开关。
