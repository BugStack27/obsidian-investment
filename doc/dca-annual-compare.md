# 定投年化与对比弹窗 — 决策记录

> 状态：✅ 已验收（2026-09-04）

## 1. 目标与范围

在基金记录块新增「定投年化」统计卡，衡量「无脑定投」策略的年化，与手动操作年化对比；点击卡片打开对比弹窗，用上下两张双 Y 轴图展示实际年化 / 定投年化 / 收益差与净值、买卖点。只做统计与展示，不改动既有收益、持仓与信号口径；不做按区间重算、不做多基金对比、不新增第三种收益率口径。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 统计区间 | 首次买入日 → 最新净值日，与手动操作总时长一致 | 两条年化必须同区间才可比 |
| 定投总额 | 所有买入金额简单求和（排除 `pending`） | 与用户实际投入总额对齐 |
| 模拟口径 | 总额平均到区间内每个有净值的交易日，每交易日买入同额，纯买入持有至期末，忽略真实卖出与分红 | 定投是反事实的「全程持有」策略 |
| 年化算法 | XIRR 资金加权，卡片与弹窗同源 | 与既有 `annual` 同算法，末端逐值可比 |
| 短持有抑制 | `MIN_HELD_DAYS = 30`，不足 30 天的点置 `null` | 避免 XIRR 在极短窗口被放大 |
| 卡片展示 | 主值为年化百分比（着色），副值为每交易日投入金额与定投天数 | 让策略口径可见 |
| 不可算降级 | 无买入、无净值、交易日不足 2 个 → 显示 `—`；卡片 `—` 仍可点击 | 样本不足时年化无意义，但实际收益与净值仍可看 |
| 对比图结构 | 图 1：实际年化 / 定投年化（左轴 %）+ 净值（右轴）；图 2：收益差（左轴）+ 净值与买卖点 | 两条年化同轴可比，收益差单独成图避免挤压 |
| 实际现金流 | 当日及之前买入 `-`、卖出 `+`、分红 `+`，期末加持仓市值（仅份额 > 0） | 末端与 `calcAnnualRate` 一致 |
| 定投现金流 | 每个有净值的交易日一条 `-perDay`，期末一条 `+累计定投份额 × 当日净值` | 末端与 `calcDcaAnnual` 完全一致 |
| 收益差 | 实际年化 − 定投年化，任一侧 `null` 时断线（`connectNulls: false`） | 宁可断线也不画假值 |
| 图表生命周期 | 弹窗持有 `chart` / `chart2` 两个实例，`onClose` 双销毁 | 漏销毁任一会泄漏 |

## 4. 关键修正与教训

- **只有 1 个定投交易日仍会算出年化** → 单日会得到垃圾值；交易日不足 2 个必须返回 `null`。
- **弹窗末端年化与卡片对不上** → 根因是简单年化 vs XIRR；统一 XIRR 后逐值一致。
- **定投现金流把无净值日也入账会导致末端漂移** → 只对 `netWorth > 0` 的交易日记 `-perDay`。
- **清仓后净投入 ≤ 0 时收益率无意义** → 该点置 `null`，曲线断开。
- **`—` 占位分支容易漏绑点击** → 定投不可算时卡片仍须可点开。
- **两张图要管两个 ECharts 实例** → `onClose` 必须双销毁。
- **`.inv-chart-body` 固定高度与弹窗图容器冲突** → 双图独立容器 + 弹窗定高、内容区滚动。

## 5. 已知边界

- 模拟忽略真实卖出与分红，与账户真实年化不是同一件事，只能作策略对比。
- 无买入、无净值或交易日不足 2 个时定投线缺失，弹窗退化为实际收益 + 净值。
- 净投入 `<= 0` 的区间没有收益率定义，曲线在该段断开。
- 收益差只表达年化差距，不反映资金规模差异。

## 6. 后续候选

- 卡片补一句口径说明（纯买入、忽略卖出分红），减少误读。
