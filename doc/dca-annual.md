# 定投年化收益率统计卡片 — 决策记录

> 状态：✅ 已验收（2026-09-04）

## 1. 目标与范围

在基金 `fund-record` 记录块的统计卡片区新增「定投年化」卡片，衡量「无脑定投」的年化收益，与「持有天数」卡片的手动操作年化对比，判断手动操作是否跑赢定投。只做统计展示，不改变既有收益、持仓与信号口径。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 统计区间 | 首次买入日 → 最新净值日，与手动操作总时长一致 | 两条年化必须同区间才可比 |
| 定投总额 | 所有买入金额简单求和（排除 pending） | 与用户实际投入总额对齐 |
| 模拟口径 | 总额平均到区间内每个有净值的交易日，每交易日买入同额，纯买入持有至期末，**忽略真实卖出与分红** | 定投是反事实的「全程持有」策略 |
| 年化算法 | XIRR 资金加权，复用现有 `xirr` | 与现有 `annual` 同算法，可直接比较 |
| 卡片展示 | `value` 为年化百分比（着色），`sub` 为每交易日投入金额与定投天数 | 让策略口径可见 |
| 降级 | 无买入、无净值、交易日不足 2 个 → 显示 `—` | 样本不足时年化无意义 |

## 3. 交付物

| 文件（相对路径） | 职责 |
|------|------|
| `src/utils/dcaCalc.ts` | `calcDcaAnnual` 与 `DcaAnnualResult`：交易日切分、每交易日投入、累计份额、期末市值、XIRR |
| `src/ui/statGrid.ts` | `summaryStats` 新增可选 `dca` 参数，末尾生成「定投年化」卡片 |
| `src/ui/recordBlock.ts` | `renderBlock` 在存在 summary 时计算并传入 dca 结果 |

## 4. 关键修正与教训

- **只有 1 个定投交易日时仍会算出年化** → 单日会得到垃圾值（如 0.1）；交易日不足 2 个必须返回 `null`，卡片显示 `—`。

## 5. 已知边界

- 模拟忽略真实卖出与分红，与账户真实年化不是同一件事，只能作策略对比。
- 无净值历史（`tradingDays` 为 0）或无买入时无定投年化。

## 6. 后续候选

- 卡片可补一句口径说明（纯买入、忽略卖出分红），减少误读。
