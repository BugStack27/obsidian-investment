# 定投对比弹窗 — 决策记录

> 状态：✅ 已验收（2026-09-04）

## 1. 目标与范围

为统计卡片中的「定投年化」增加点击交互：弹窗内用一张双 Y 轴图展示实际累计收益率曲线、模拟定投累计收益率曲线（左轴 %）与净值曲线（右轴），便于逐日对比手动操作与无脑定投。不做按区间重算，不做多基金对比。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 实际收益率口径 | 累计收益率 =（持仓市值 − 净投入）/ 净投入，逐日计算 | 与定投收益率同为「投入资金回报率」，同一基准 |
| 净投入定义 | Σ买入金额 − Σ卖出金额，排除 pending；分红不改份额与净投入 | 分红不改变投入本金 |
| 布局 | 单图双 Y 轴：左轴收益率(%)，右轴净值 | 两条收益率同轴可比，净值异轴不压缩比例 |
| 时间轴 | 与 `calcDcaAnnual` 完全相同的交易日集合（首次买入日 → 最新净值日） | 保证两条曲线逐日对齐 |
| 定投不可算 | 仅跳过定投线，仍渲染实际收益率 + 净值，并给出提示 | 不因策略无法模拟而让弹窗失效 |
| 触发 | 点击「定投年化」卡片，`—` 占位时同样可打开 | 缺定投线仍可看实际收益与净值 |
| 图表生命周期 | 复用 `initChart` / `disposeChart` / `CHART_COLORS`，`onClose` 销毁并清空内容 | 与既有弹窗一致，避免泄漏 |

## 4. 关键修正与教训

- **清仓后净投入 ≤ 0 时收益率无意义** → 该点置 `null`，曲线断开，不输出极端值。
- **`—` 占位分支容易漏绑点击** → 定投不可算时卡片仍须可点开，否则恰好是最需要看实际收益的场景失去入口。

## 5. 已知边界

- 无买入、无净值或交易日不足 2 个时系列为 `null`，弹窗退化为占位提示。
- 净投入 `<= 0` 的区间没有收益率定义，曲线在该段断开。
- 分红不改变净投入，其收益体现在持仓市值中。
