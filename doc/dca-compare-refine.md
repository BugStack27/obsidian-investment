# 定投对比弹窗精修 — 决策记录

> 状态：✅ 已验收（2026-09-04）

## 1. 目标与范围

修正弹窗曲线末端年化与统计卡片不一致的问题，并在原图下方新增一张「收益差」对比图。不改动卡片自身算法，不新增第三种收益率口径。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 年化口径 | 弹窗曲线由简单年化 `(1+累计收益率)^(365/天数)−1` 改为逐日 XIRR | 卡片用的是 XIRR，两种算法对资金时间价值计入方式不同，末端必然不等 |
| 定投现金流 | 每个有净值的交易日一条 `-perDay`，期末一条 `+累计定投份额 × 当日净值` | 末端与 `calcDcaAnnual` 完全一致 |
| 实际现金流 | 当日及之前发生的买入 `-`、卖出 `+`、分红 `+`，期末加持仓市值（仅份额 > 0） | 末端与 `calcAnnualRate` 一致 |
| 短持有抑制 | `MIN_HELD_DAYS = 30`，持有不足 30 天的点置 `null` | 避免 XIRR 在极短窗口被放大 |
| 不可算降级 | XIRR 返回 `null` 或天数不足时该点置 `null`，曲线 `connectNulls: false` | 宁可断线也不画假值 |
| 第二张图 | 左轴收益差 = 实际年化 − 定投年化（%），右轴净值 + 买卖点，独立 legend | 仿第一张图的双轴布局，直观看出手动操作领先多少 |
| 生命周期 | 持有 `chart` / `chart2` 两个实例，`onClose` 双 `disposeChart`；买卖点位构建抽为共享方法 | 上下两图复用同一套交易点 |

## 3. 交付物

| 文件（相对路径） | 职责 |
|------|------|
| `src/utils/dcaCompareCalc.ts` | 逐日 XIRR 年化（保留返回结构），移除 `annualize`，`MIN_HELD_DAYS` 抑制 |
| `src/ui/dcaCompareModal.ts` | 上下双图；图 1 实际/定投年化 + 净值 + 买卖点，图 2 收益差 + 净值；共享 `buildTradePoints` |
| `styles.css` | 双图垂直布局、弹窗高度与内部滚动，修复图表容器高度冲突 |

## 4. 关键修正与教训

- **弹窗末端年化与卡片对不上** → 根因是简单年化 vs XIRR；统一 XIRR 后末端与卡片逐值一致。
- **定投现金流把无净值日也入账会导致末端漂移** → 只对 `netWorth > 0` 的交易日记 `-perDay`。
- **`年化率之差` 不能用「累计收益率之差」替代** → 收益差明确取两条 XIRR 年化之差，与卡片口径同源。
- **两张图要管两个 ECharts 实例** → 关闭时漏销毁其一会泄漏；`onClose` 必须双销毁。
- **`.inv-chart-body` 固定高度与弹窗图容器冲突** → 双图独立容器样式 + 弹窗定高、内容区滚动。

## 5. 已知边界

- 持有不足 30 天时无年化点，曲线呈现为空或极短。
- 任一侧年化为 `null` 的日期，收益差点同样为 `null`（断线）。
- 收益差只表达年化差距，不反映资金规模差异。
