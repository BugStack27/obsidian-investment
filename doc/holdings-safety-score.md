# 持仓分析安全度评分 — 决策记录

> 状态：✅ 已验收（2026-11-04）

## 1. 目标与范围

在同一「持仓分析」页签内做三处改动：① 删掉顶部整段说明文字；② 「手动补充」与「对比分析」由两行合并为一行并移动到页签下方最顶部；③ 新增「安全度分析」卡，用阈值市值占比加权出「谨慎 / 激进」两档评分。不做：评分历史趋势、行业分档阈值、分位口径。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 评分公式 | 谨慎 = `0.5·PE<15 + 0.3·PB<1.5 + 0.2·PE×PB<22.5`；激进 = `0.5·PE<30 + 0.3·PB<3 + 0.2·PE×PB<45` | PE 是主口径；PB 与 PE 非独立维度（`PB = PE × ROE`），权重下调至 30% |
| 占比口径 | 市值加权（`belowCap / totalCap`） | 反映真实资金暴露；只数占比作灰字副信息（`6/10`） |
| PE×PB 阈值 | 22.5 / 45 | 22.5 = 15×1.5 为格雷厄姆标准；激进档取 2 倍放宽到 45，不用 30×3=90（几乎无筛选力） |
| 无数据子项 | 权重在剩余子项内归一化，不按 0 分 | 否则一只全无 PE 的基金会被判为「极度危险」 |
| 覆盖度 | 子卡底部「覆盖 x% 市值」= 该指标有效市值 ÷ 全部持仓市值，仅在 <100% 时渲染 | 提示评分分母不完整（亏损股被剔除会让分数虚高） |
| 对比显示 | 每格 `当时 → 当前`，仅当前值着色，当时值灰 | 两个彩色数字并列会抢视线；方向与分析卡统一为「当时 → 当前」 |
| 色阶 | ≥75 安全 `#1d9e75` / 50–74 中性 `#fac775` / 25–49 偏险 `#d85a30` / <25 危险 `#e24b4a` | 拉开亮度而非仅色相：深色主题下黄与橙相邻难分 |
| 主题适配 | 颜色挂在 `--s-color` 变量上，浅色主题另有更深取值 | `.inv-level-*` 只定义变量，元素统一 `color: var(--s-color)` |
| 等级标签 | 只在总分块出文字（安全/中性/偏险/危险），子卡靠颜色 | 子卡内容宽约 100px，再放标签会挤 |
| 空态 | 全部无估值数据时整卡不渲染，显示「暂无估值数据」 | 0 分会被读成「极度危险」 |
| 布局 | 控制行置顶 → 安全度卡（标题行 + 4 列网格）→ 三图 | 用户指定控制行在卡上方；原设计稿放卡下方被否 |
| 顶部说明 | 整行删除，缺失数据提示并入覆盖度行 | 用户要求去掉 |

### PB 阈值从 1/2 改为 1.5/3 的原因

- **分位不对齐**：`PE<15` 对应 A 股偏低估的三成左右，`PB<1` 是破净、只占一成出头。同一档内两个子项难度差一档，PB 子项被系统性压低。
- **行业一集中就恒定**：消费/医药/科技基金里 `PB<2` 可能一只都没有，40% 权重项恒为 0，总分上限被锁死，横向比较失去区分度。
- **乘积不自洽**：`15 × 1.5 = 22.5` 是格雷厄姆经典标准；若 PB 取 1.5，PE×PB 的谨慎档理应对应 22.5（原为 30，已随本轮一并改为 22.5 / 45）。

## 4. 关键修正与教训

- **阈值不能脱离分布谈**：固定 PB 阈值隐含「所有公司 ROE 相同」的假设，行业一旦集中就退化。先看达标只数（`x/10`）再定阈值。
- **权重分配要承认指标相关**：PB 与 PE 同源于盈利与净资产，等权会重复计价同一件事。
- **卡片等高靠 `margin-top: auto`**：覆盖度行条件渲染会让子卡高度不一，用弹性沉底对齐而非固定高度。
- **颜色用变量挂类名**：直接内联 hex 无法跟随浅色主题，实际实现用 `--s-color` + `.theme-light` 覆盖。

## 5. 已知边界

- 绝对阈值不区分行业与个股 ROE；银行与科技混在同一把尺子上。
- 只数占比仅作副信息展示，不参与评分。
- 对比模式下 `当时` 口径依赖历史估值接口，单只无数据时该子项显示为 `—`。
- 激进档 PE×PB 取 45（2 倍放宽）而非 `30×3=90`，是筛选力与口径一致性的折中，不是严格的阈值乘积。
