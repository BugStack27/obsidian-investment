# 净值走势与趋势通道图成本线 — 决策记录

> 状态：✅ 已验收（2026-09-23）

## 1. 目标与范围

在净值走势图与趋势通道图上建立三层成本参照：静态持仓成本线（水平参考）、逐日加权成本趋势线（随买入阶梯变化）、累计成本线（仅在高于持仓成本时叠加）。只做展示，不新增图例开关，不改净值线、均线、通道、买卖标记与数据口径。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 静态持仓成本线 | `markLine` 固定 `summary.avgCostPerShare`，常显、不进图例 | 成本快照，无需逐日重建 |
| 静态线样式 | 琥珀金 `#D97706` 虚线，标签「持仓成本」+ 四位小数等宽 | 与买入红、卖出绿、均线蓝区分 |
| 逐日成本趋势线 | 每个净值日输出「累计买入成本 / 累计买入份额」，`step: 'end'`，`showSymbol: false` | 成本随买入阶梯跳变，贴合实际持仓成本 |
| 趋势线配色 | `CHART_COLORS.secondary` 蓝，`z` 介于净值线与买卖点之间 | 延续既有成本线语义且不遮挡标记 |
| 累计成本口径 | `totalInvested / holdShares`，含已实现盈亏影响 | 与持仓成本并列回答「全部投入摊到当前份额」 |
| 累计成本触发 | 严格大于持仓成本才画；相等或更低不画 | 从未卖出的基金两口径相等，避免重合 |
| 累计成本样式 | 与持仓成本同色系点线，标签「累计成本 x.xxxx」 | 不新增配色，靠线型区分 |
| 标签位置 | 通道图两条标签分别 `insideEndTop` / `insideEndBottom` | 数值接近时避免叠字 |
| 成本计算入口 | `channelModal` 的 `costInfo` 统一返回两条成本 | 原先两处各算一遍，易分叉 |
| 区间联动 | 趋势线随近 6 月 / 1 年 / 3 年 / 全部重算；两条静态线保持全区间值 | 趋势线必须与净值日期同源，静态线是快照 |

## 4. 关键修正与教训

- **无买入日不能跳过** → 仍按当前份额口径逐日连续输出成本，否则趋势线断点。
- **无持仓或成本 `<= 0` 不得画线** → 会画出一条贴底假成本线。
- **`markLine` 从单条对象改为多行 `data`** → 只画持仓成本时的样式、图例与 tooltip 必须逐项保持不变，这是主要回归点。
- **两条成本线语义不同** → 水平线为全区间整体加权，趋势线为逐日加权，共存而非替代。
- **两个入口各传各的成本** → 指标分析弹窗与信号弹窗切换基金时必须随该基金成本刷新。

## 5. 已知边界

- 成本只在买入时变化，卖出不降低单位成本（口径为累计买入加权）。
- 累计成本为静态值，切换图表区间时保持全区间数值，不随区间缩放。
- 两条成本线均不进入图例、不参与 tooltip，也不可隐藏。
- 无持仓、`holdShares <= 0` 或成本缺失时两条线都不画，且不报错。
