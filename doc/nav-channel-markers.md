# 净值走势与趋势通道图买卖标记 — 决策记录

> 状态：✅ 已验收（2026-09-23）

## 1. 目标与范围

统一两张叠加买卖点的图表的视觉与交互：标记点尺寸缩小、净值线改中性色、实心点去白描边，并让净值走势卡 tooltip 展示当日买卖金额。不改标记数量与位置，不改坐标轴、图例与数据口径；K 线图标记保持不动。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 标记尺寸 | 净值图实心 5px、光晕 8px；通道图 10px → 5px | 原尺寸密集时大面积覆盖曲线 |
| 内圈描边 | 1.5 → 1，随后实心点直接去掉 `borderColor` / `borderWidth` | 5px 下白边占比过大，削弱实心色块 |
| 光晕圈 | 净值图外层半透明光晕保留，`silent: true` 且层级高于净值线与成本线 | 与描边无关，属另一视觉层 |
| 净值线颜色 | 新增 `CHART_COLORS.navLine = '#475569'` 中性石板灰；面积渐变由该色派生 | 原红色与买入点撞色，灰不与红绿蓝抢色 |
| 面积渐变 | `rgba(71, 85, 105, 0.15)` → 全透明，与线色同源 | 线色与填充必须同步，否则残留红底 |
| tooltip 交易范围 | 仅落在净值日且非 `pending` 的买 / 卖 | `pending` 缺净值，本就落不到净值日 |
| 同日多笔 | 同类合并为一行、金额累加；买卖各占一行不并净额 | 与通道图口径一致，避免多行噪声 |
| 金额格式 | `toFixed(2)` + 等宽；买入 `-¥` 配 profit 红、卖出 `+¥` 配 loss 绿 | 买入流出、卖出流入，红绿语义与图上一致 |
| 点位净值 | tooltip 不展示 | 卡内已有「净值」一行，重复无增量 |
| 元数据挂载 | 只挂内圈实心点，光晕不挂 | 否则同一笔交易在 tooltip 中重复计入 |
| 通道图契约 | `series id`（`tx-buy` / `tx-sell`）、`name`、data 字段 `_date` / `_nav` / `_amount` / `_type` 保持不动 | tooltip 依赖这些字段 |

## 3. 交付物

| 文件（相对路径） | 职责 |
|------|------|
| `src/ui/charts/theme.ts` | `CHART_COLORS` 新增 `navLine: '#475569'`，颜色常量集中管理 |
| `src/ui/charts/navChart.ts` | `pushScatter` 尺寸与内圈 `itemStyle`；净值 series 线色与渐变；`TxMarker` 扩展日期 / 金额 / 类型，按 x 轴索引聚合并输出 tooltip 金额行 |
| `src/ui/charts/trendChannel.ts` | `pushScatter` 尺寸与 `itemStyle` 精简；净值 series 线色改 `navLine` |

## 4. 关键修正与教训

- **面积渐变最易漏改** → 线色与渐变必须同时由 `navLine` 派生，否则图上仍出现红色 rgba。
- **按净值日聚合是金额展示的前提** → 标记点改为按 x 轴索引的 `Map`，跳过 `pending` 与类型不符的交易，同日同类金额累加，末尾按索引升序输出。
- **光晕若也带元数据会重复计数** → 元数据只写在实心系列。
- **散点数据项可能缺少元数据** → 先按 `_type` 识别，再用 `_date !== dateStr` 兜底比对，并校验金额为有限正数。
- **原 tooltip 内容不可回归** → 先拼原 `html` 再追加金额行，其余各行样式与顺序不变。

## 5. 已知边界

- 标记点变小后 ECharts hover 命中区域同步缩小，极端密集处悬停精度下降（已确认接受）。
- 交易日落在所选区间（近 6 月 / 1 年等）之外时不出现金额行。
- 同日买入与卖出各占一行，不合并为净额；金额为 0 或无法解析的历史记录不展示对应行。
- `navChart.ts` 的静态持仓成本 `markLine` 仍为红色，与买入点同色，本次刻意未处理。
