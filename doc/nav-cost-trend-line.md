# 净值走势图成本趋势线 — 决策记录

> 状态：✅ 已验收（2026-09-04）

## 1. 目标与范围

基金详情「净值走势」图原先只有一条静态水平成本虚线（`markLine`，固定在 `summary.avgCostPerShare`，即全区间整体加权成本）。本次新增一条随时间变化的每日加权成本趋势线，反映成本随历次买入的演进；静态水平线保留。不涉及收益曲线、通道图与买卖点渲染。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 趋势线语义 | 按净值日期逐日推进，累计买入成本 / 累计买入份额 | 与实际持仓成本口径一致，买入新价格时呈阶梯变化 |
| 静态水平线 | 保留不动 | 两种成本视角共存：全区间 vs 逐日 |
| 渲染形态 | `type: 'line'` + `step: 'end'`，`name: '持仓成本'`，`showSymbol: false`，`z` 介于净值线与买卖点之间 | 阶梯语义贴合成本跳变，且不遮挡买卖点 |
| 配色 | `CHART_COLORS.secondary`（`#3B82F6` 蓝），与净值主线红区分 | 蓝为既有成本线色，语义连续 |
| tooltip | 存在 `_avgCost` 时追加「持仓成本」一行，等宽字体、`toFixed(4)` | 与图上数值一致，便于核对 |
| 区间联动 | 切换近 6 月/1 年/3 年/全部时随净值区间重算 | 成本序列与净值日期同源，不得错位 |

## 4. 关键修正与教训

- **无买入日** → 仍按当前份额口径保留加权成本并逐日连续输出，不能跳过该日。
- **两条成本线语义不同** → 水平线为全区间整体加权，趋势线为逐日加权，二者共存而非替代。
- **配色需与移动端 `invest-app` 一致** → `CHART_COLORS` 与移动端主题对齐，不新增临时色值。

## 5. 已知边界

- 成本只在买入时变化，卖出不降低单位成本（口径为累计买入加权）。
