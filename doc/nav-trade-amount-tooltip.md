# 净值走势卡 tooltip 显示买卖金额 — 决策记录

> 状态：✅ 已验收（2026-09-23）

## 1. 目标与范围

「净值走势」卡已画出买卖标记点，但 tooltip 只有净值、涨跌、累计收益、持有收益、持仓成本，缺交易金额；趋势通道图的 tooltip 已支持。本次为净值走势卡补上命中净值日的买入/卖出金额。不改变标记点数量、位置与配色，不改趋势通道图。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 展示哪些交易 | 仅落在净值日且非 `pending` 的买/卖 | 与 `trendChannel.ts` 的 `mergeMarkers` 口径一致；pending 缺净值，本就落不到净值日 |
| 同日多笔 | 同类合并为一行、金额累加 | 与趋势通道图一致，避免多行噪声 |
| 符号与配色 | 买入 `-¥` 配 `CHART_COLORS.profit`，卖出 `+¥` 配 `CHART_COLORS.loss` | 买入为流出、卖出为流入，红绿语义与图上一致 |
| 格式 | `toFixed(2)` + 等宽字体 | 与趋势通道图 tooltip 统一 |
| 点位净值 | 不展示 | 卡内已有「净值」一行，重复无信息增量 |
| 行序 | 追加在持仓成本行之后 | 原有 5 行位置不变 |
| 元数据挂载 | 只挂在内圈实心点（`inner === true`），光晕不挂 | 否则同一笔交易在 tooltip 中重复计入 |

## 3. 交付物

| 文件（相对路径） | 职责 |
|------|------|
| `src/ui/charts/navChart.ts` | `TxMarker` 扩展 `date` / `amount` / `type`；`txMarkers` 改为按 x 轴索引的 `Map` 聚合；`pushScatter` 内圈写入 `_date` / `_nav` / `_amount` / `_type`；`buildNavOption` 的 `tooltip.formatter` 追加买卖金额行 |

## 4. 关键修正与教训

- **按净值日聚合是前提** → 标记点改为 `Map<number, TxMarker>`，跳过 `pending` 与类型不符的交易、同日同类金额累加、末尾按 index 升序输出，保证标记顺序稳定。
- **光晕若也带元数据会重复计数** → 元数据只写在实心系列，tooltip 遍历 `params` 时同一笔只命中一次。
- **散点数据项可能缺少元数据** → 遍历时先按 `_type` 识别，再用 `_date !== dateStr` 兜底比对防止跨分类误匹配，并对金额做 `Number.isFinite(amount) && amount > 0` 校验。
- **原 tooltip 原有内容不可回归** → 实现改为先拼 `html` 变量再追加金额行，其余 5 行样式与顺序不变。

## 5. 已知边界

- 交易日落在所选区间（近 6 月/1 年等）之外时不出现金额行。
- 同日买入与卖出各占一行，不合并为净额。
- 金额为 0 或无法解析的历史记录不展示对应行。
