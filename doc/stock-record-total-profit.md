# 股票记录块总收益卡 — 决策记录

> 状态：✅ 已验收（2026-11-01）

## 1. 目标与范围

股票做过部分卖出后，记录块原来只显示剩余持仓的浮盈，已兑现的那部分收益完全不计，与整段持仓的真实收益差出一截。本次在汇总里补一套**总口径**，多渲染一张「总收益」卡，让卖出后仍能一眼看到整段持仓的收益与收益率，与基金记录块同口径。

只动展示层的汇总与卡片，表格、写入链路、K 线标记均不改。

## 2. 关键决策

| 决策点 | 结论 | 理由 |
|------|------|------|
| 两套口径并存 | `持仓盈亏` = 剩余市值 − 成本基准；`总收益` = 市值 − 净投入 + 分红 | 持仓口径回答「现在浮盈多少」，总口径回答「这段持仓一共赚了多少」，语义不同不合并 |
| 净投入 | 买入金额累计 − 卖出回款累计 | 卖出回笼的钱已不再是投入，继续留在分母里会把收益算低 |
| 总收益率分母 | 累计**买入金额**，非净投入 | 与基金 `summarizeHolding` 一致；净投入做分母会在减仓后虚高、清仓时归零 |
| 分红 | 股票记录块也累计分红金额进总收益 | 表格本就有「分红」类型，真实收益不能漏 |
| 卡片渲染条件 | 有卖出回款或有分红时才渲染 | 从未卖出过的标的，总收益与持仓盈亏数值完全相同，多一张卡只是噪声 |
| 行情失败时的总收益 | 未清仓则显示 `—`；已清仓仍出数 | 未清仓时市值按 0 会得出巨额假亏损；已清仓市值恒为 0，与行情无关，全是已兑现收益 |

## 4. 关键修正与教训

- **不能把总收益写成「持仓盈亏 + 已实现收益」两段相加的临时量**：直接从「市值 − 净投入 + 分红」推导，只有一个算式，卖出回款自然进账，不必单独维护已实现收益的游标。
- **收益率分母不能沿用成本基准**：减仓后成本基准随剩余持仓缩小，用它会算出与总收益不匹配的夸张收益率。

## 5. 已知边界

- 卖出记录若 `金额` 为 0（只录了数量），无法推导回款，总收益会被算低——股票侧没有净值那样的推导来源，保持原样不臆造。
- 分红明细没有独立汇总卡，只在总收益中体现。

## 6. 后续候选

- 总收益卡副标题可加「已兑现」分项（卖出回款 − 对应成本），需要 FIFO/均价分摊口径支持。
